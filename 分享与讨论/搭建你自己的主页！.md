## FAQ 常见问题

**1. 页面文件忘了加 `.md` 后缀**
现象：GitHub 上能打开，网站上点进去空白或打不开。
解决：文件名必须以 `.md` 结尾。反过来，**侧边栏链接不要写 `.md`**。

**2. 单换行被渲染成空格**
现象：两行字在网页上挤成一行，中间多一个缝。
解决：行尾加 `<br>`；或空一行分段；或改成 `-` 列表。
去搜索Markdown规则

**3. `#` 或 `-` 后面漏了空格**
现象：网页上原样显示 `###标题`、`-项目` 这些字符。
解决：`## 标题`、`- 项目` —— 标记符后面**必须有一个空格**，否则语法不成立。

**4. 页面缺 `#` 一级标题**
现象：页面没有大标题、字号特别小、看不出层级。
解决：每页第一行写 `# 页面名`，页内小节用 `##`、`###`。

**5. 侧边栏写错或忘了挂**
现象：页面存在，但左边没入口、搜索也搜不到（索引是按侧边栏抓的）。
解决：在 `_sidebar.md` 加 `  * [显示名](/分类/文件名)` —— **缩进 2 空格、链接不带 `.md`**；分组标题写成不带链接的 `* 学习`。

**6. git 连不上 GitHub**
现象：`Failed to connect to github.com:443` 或 `schannel: SEC_E_NO_CREDENTIALS`。
原因：浏览器走系统代理，git 不读 IE 代理设置。
解决：让ai帮忙调试终端窗口，一般就是让它配一下代理：

```powershell
git config --global http.proxy http://127.0.0.1:7890
git config --global http.sslBackend openssl
```

**7. push 被拒绝**
现象：`! [rejected] ... (fetch first)`。
原因：你在网页上改过，本地也有新提交，两边分叉了。
解决：让ai辅助你决断怎么处理，通常的顺序是先拉后推：

```powershell
git pull --rebase
git push origin main
```

**8. 改完看不到 / 删了还能搜到**
现象：内容不更新；或者搜索里还留着已经删掉的页面。
解决：`Ctrl+F5` 强刷（重启浏览器没用）；搜索索引存在浏览器本地缓存里，把 `index.html` 里 `namespace` 的版本号 +1，就能强制重建索引。

**9. URL 停在已经删掉的页面**
现象：正文显示「404 - Not found」，但左边栏是正常的。
解决：把地址栏里 `#` 及其后面的内容删掉，只留域名；或者点侧边栏的「返回首页」。按 F5 无效是因为 hash 还留在地址里。

**10. Windows 下用 PowerShell 写中文 md 变乱码**
现象：用 `Set-Content`、`Out-File`、`>` 写文件，中文全乱了。
原因：Windows PowerShell 5.1 默认按 GBK 写，md 需要 UTF-8。
解决：用 VS Code 或记事本保存为 UTF-8；必须用命令行时加 `-Encoding UTF8`。

---

**另外三个一次性问题**（遇到概率低但很致命）：

- 仓库必须叫 `<用户名>.github.io`，并在 **Settings → Pages** 开启，才有裸域名；
- **`.nojekyll` 绝对不能删** —— 删了 Jekyll 会吃掉 `_sidebar.md` 和所有中文目录，目录整片消失；
- **图片先压缩再传**这样手机打开快
